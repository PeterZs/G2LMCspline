G2LMC for MATLAB
Lightweight MATLAB toolbox for G2LMCspline.
Files
G2Curve.m Core class
main_interactive.m Interactive curve editor
main_draw.m Batch plot script
data/data_elephant.mat Sample data
Features
Interactive point dragging
W/R keys to adjust local curvature

Quick Start
Interactive:
main_interactive
Batch plot:
main_draw
Usage
load('.\data\data_elephant.mat');
Requirements
MATLAB R2022b or later
No additional toolboxes
